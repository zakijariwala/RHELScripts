# RHELScripts

Scripts I write at home and try out at work on RHEL 8/9 servers. The ones
that prove useful join my daily workflow.

Each script runs on one server: put it on the server (typed or copied),
run it when needed. Scripts are short enough to type by hand.

| Script | What it does |
|---|---|
| [health-check](scripts/health-check/) | OS, disk, time, agents; database, ASM, listener and cluster on DB nodes |

[docs/inventory.md](docs/inventory.md) lists the servers.
[docs/planned.md](docs/planned.md) holds approved designs not built yet.
